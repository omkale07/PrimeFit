# 🏋️ PrimeFit

PrimeFit is a modern **Gym & Fitness Website** built with **HTML, CSS, and JavaScript**.  
It provides a professional online presence for a fitness center with sections like Home, About, Programs, Trainers, Gallery, and Contact.

---

## 🚀 Features
- Responsive and clean design  
- Hero section with motivational quotes  
- About & Programs details  
- Trainer profiles  
- Image gallery  
- Contact section with details  

---

## 🛠️ Built With
- **HTML5** – Website structure  
- **CSS3** – Styling & layout  
- **JavaScript** – Interactivity
